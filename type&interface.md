Both **Type** and **Interface** can be used in TypeScript to define the type of data inside an object.

**Type** can be used to define the data type of a specific variable. It can also be used to define various types such as Primitive, Union, Tuple, Function, and Object types.

**Interface** is used to define the structure of an object.

When you need to define different kinds of types, **Type** is used. When you need to define the structure of an object, **Interface** is generally used.
